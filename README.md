# DNA Sequence Analyzer

## Purpose
The DNA Sequence Analyzer processes DNA sequences to identify nucleotide masses, calculate nucleotide percentages, and detect the presence of proteins and codons. 

## Features
- Analyzes DNA sequences
- Calculates nucleotide masses
- Computes nucleotide percentage compositions
- Identifies codons and potential proteins
- Generates visual graphs of DNA analysis results
- Creates a website displaying the analyzed DNA information and findings
- Saves analysis results to a user-specified text file

## Version
May 18, 2022

## How to Run
1. Launch the program.
2. Enter or load the DNA sequence data.
3. Review the generated analysis, graphs, and website output.
4. Save the results to a text file when prompted.

## Output
The program generates:
- DNA sequence analysis results
- Nucleotide mass calculations
- Percentage breakdowns of nucleotides
- Protein/codon detection results
- Visual graphs
- A website containing the DNA analysis and visualizations
- A text file containing the saved results
